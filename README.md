# Cedar & Form

A complete chair furniture shop demo with a React storefront, a Spring Boot API, and a local SQLite database.

## Run it

1. Start the API: `cd backend && mvn spring-boot:run`
2. In a second terminal start the store: `cd frontend && npm install && npm run dev`
3. Open the local address displayed by the frontend.

The database file is created automatically at `backend/data/cedar-form.db`. The catalog is seeded at startup.
